# duck-Karaoke



## Setup

### Download Vocal remover  

```

#The vocal remover can be downloaded from the following link, need to chose the latest version and replace the "<tag>":

curl -L -o vocal-remover-v6.0.0b4.zip "https://github.com/tsurumeso/vocal-remover/releases/download/<tag>/vocal-remover-v6.0.0b4.zip"

#Ex:
curl -L -o vocal-remover-v6.0.0b4.zip "https://github.com/tsurumeso/vocal-remover/releases/download/v6.0.0b4/vocal-remover-v6.0.0b4.zip"

#Unzip the downloaded file:

unzip vocal-remover-v6.0.0b4.zip -d vocal_remover

```
